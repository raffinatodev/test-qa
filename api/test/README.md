# 🧪 Testes Automatizados - API Raffinato

Este projeto contém os testes automatizados para a API da Raffinato, usando Jest + TypeScript.

## ▶️ Como rodar os testes

1. **Clone o repositório da API**  
   ```bash
   git clone https://github.com/raffinatodev/test-qa.git
   cd test-qa/api
Instale as dependências da API
yarn install
Inicie a API localmente
yarn start
Acesse o diretório dos testes
cd ../test
Instale as dependências dos testes
yarn install
Execute os testes
yarn test
